# Changelog

Release changes follow [Keep a Changelog](https://keepachangelog.com/) and [Semantic Versioning](https://semver.org/).

## [0.1.1] — 2026-11-04

### Changed
- Established proportional Small, Standard and High-risk development paths with explicit owner overrides.
- Changed the normal sequence to code review before final testing.
- Allowed Small changes to stay in one chat through owner approval; context handoff remains a judgment call, not a token threshold.
- Clarified plan archiving, evidence tied to exact revisions and revalidation after changes to the PR or `main`.
- Kept one agent entrypoint, stage instructions, coding sanity checks and a user-facing README.
- Updated the PR template for planning-only and implementation changes.
