# Sources and conventions

The repository-local skills use the common `SKILL.md` convention and are influenced by:

- [AGENTS.md](https://agents.md/) for repository instructions.
- [OpenAI Agent Skills](https://github.com/openai/skills) for local skill format.
- [Superpowers](https://github.com/obra/superpowers) for systematic debugging.
- Public engineering practices for code review and iterative implementation.

The local skills are project-adaptable guidance, not copies of third-party skill packs.
