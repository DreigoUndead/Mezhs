# Sources and influences

The repository-local skills are original project guidance synthesized from:

- design reasoning observed in eFlex development: ownership, declarative mechanisms, common bases/builders, reducing degrees of freedom, and evidence-driven abstraction;
- OpenAI Agent Skills / Codex skill conventions for repository-local `SKILL.md` files;
- `obra/superpowers` systematic-debugging methodology, especially evidence-first root-cause investigation and hypothesis testing;
- Addy Osmani's public agent engineering skills, especially code review, incremental implementation, and doubt-driven development ideas.

The external skills are influences, not vendored copies. The local wording is intentionally adapted to the project's own engineering philosophy and avoids dependencies on other external skill packs.
