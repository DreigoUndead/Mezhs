# Development

The Developer implements the assigned task-plan steps.

## Implementation

- Inspect relevant existing code and responsibilities before
  modifying them.
- Implement the agreed behavior.
- Write or update tests for changed behavior and meaningful
  regression risks, using the project's existing testing conventions.
- When fixing bugs or test failures, establish the cause.
  Use [Systematic Debugging](skills/systematic-debugging/SKILL.md).
- Keep code, tests and relevant specifications consistent.

## Developer verification

- Run relevant tests, builds and other checks that verify
  the implemented behavior.
- Inspect the diff for regressions, unintended changes and
  incomplete work.
- Record actual test results, limitations and checks not performed.

## Outcome

- **Complete:** Commit and push changes on the task branch.
  Continue to the next required step or role defined by the plan.
- **Blocked:** Report the unresolved obstacle or decision
  to the owner.
